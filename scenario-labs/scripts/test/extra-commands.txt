# Every command in the lab pages that run-lab.sh --all does not run by itself:
# commands in tips, exam tips, "Read only" boxes, tables and the "explained" pages, and the
# "Check:" boxes of the mock exam solutions. run-all.sh runs each section right after its lab,
# so the cluster is in the state the page describes.
#
# Format: "## <lab>" starts a section. A "#" line says where the next command comes from.
# One command per line; it runs with bash -c in the lab's folder.
#   !command   must FAIL (the page says it fails)
#   ~command   keeps running (watch, follow, port-forward): stopped after 8 seconds, that is fine
# Values the page leaves to you (NAME, <pod>, ...) are filled in with real ones.
# Throwaway objects go in the namespace "cmdtest", which each section deletes again.
